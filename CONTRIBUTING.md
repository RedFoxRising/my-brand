# Contributing

This is my personal site, not a project looking for contributors. I'm not
accepting pull requests for content, design, or structure — those are personal
editorial choices.

**Found something broken?** Open an issue. Typos, dead links, layout bugs on a
device I don't have, or anything that renders wrong in one language but not the
other are all genuinely useful to hear about.

**Want to reuse the setup?** Go ahead — the code is MIT (see [LICENSE](LICENSE)).
It started as a fork of
[student-branding-starter](https://github.com/lukelittle/student-branding-starter)
by Lucas Little, which is a better starting point than this repo if you want a
clean base. If you're adapting my customizations, `docs/DECISIONES.md` explains
why the non-obvious ones exist.

Note that the site content itself — posts, project writeups, CV — is not
covered by the MIT license.
